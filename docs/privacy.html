Política de privacidad

YouTube Claudio es una herramienta de uso personal. Solo la utiliza su propietario para gestionar sus propios canales de YouTube.

  • Usa los Servicios de la API de YouTube y la API de YouTube Analytics para leer y editar datos de los canales del propietario (videos, listas, metadatos, programación y estadísticas).
  • Las credenciales de acceso se guardan únicamente en la computadora del propietario. No se envían a servidores de terceros.
  • No recopila, vende ni comparte datos de ninguna persona.
  • No accede a datos de otros usuarios de YouTube.
  • El propietario puede revocar el acceso en cualquier momento desde https://myaccount.google.com/permissions.

Al usar la API de YouTube, se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.
